# 安装 FDE 制度提取 Skill

## 从开发分支用 npm 安装

需要 Node.js 18 或更高版本、npm，以及对私有仓库 `Eveosev/dataagent` 的 GitHub SSH 读取权限。在安装过 Node.js 的普通用户终端运行，无需 npm 账号。

**Codex**

```sh
npm install -g 'git+ssh://git@github.com/Eveosev/dataagent.git#feat/fde-skill-npm' && dataagent-skill codex
```

**Claude Code**

```sh
npm install -g 'git+ssh://git@github.com/Eveosev/dataagent.git#feat/fde-skill-npm' && dataagent-skill claude
```

npm 安装工具和 Skill 文件。后半条命令把所选宿主的个人技能目录连接到这份安装。两种宿主都用时，npm 只需安装一次。若只想在一个项目试用，在项目根目录运行 `dataagent-skill codex --project` 或 `dataagent-skill claude --project`。

重跑安装命令可跟进开发分支；固定版本时把 `#feat/fde-skill-npm` 换成目标提交的完整 SHA。以前用 ZIP 安装过的同名目录会保留，命令会提示其位置。要改用 npm 管理，先把旧目录移到技能目录之外，再运行 `dataagent-skill codex` 或 `dataagent-skill claude`。[npm 的 Git 安装说明](https://docs.npmjs.com/cli/v11/commands/npm-install/)

## 从 ZIP 安装

拿到 `fde-engineer.zip` 后，在压缩包所在目录打开终端。下面是 macOS 和 Linux 上的首次安装命令。默认装给 Codex；使用 Claude Code 时，将第一行改成 `skill_dir="$HOME/.claude/skills"`。[Codex 的个人技能目录](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills) · [Claude Code 的个人技能目录](https://code.claude.com/docs/en/skills#where-skills-live)

```sh
skill_dir="$HOME/.agents/skills"
mkdir -p "$skill_dir" && unzip -n fde-engineer.zip -d "$skill_dir"
```

解压后，入口是 `$skill_dir/fde-engineer/SKILL.md`。同目录下的 `references/` 和 `scripts/` 一起保留。引文核验工具使用 Python 3 标准库。

## 验证

新建对话，附上一份制度文件。在 Codex 输入「`$fde-engineer` 帮我提取附件里的差旅报销规定，每条附出处」；在 Claude Code 输入「`/fde-engineer` 帮我提取附件里的差旅报销规定，每条附出处」。给一份明确原件时会直接提取；给两份版本、只要求处理其中一份时会先询问版本。
