# 安装现场交付与运维 Skill

## 从开发分支用 npm 安装

需要 Node.js 18 或更高版本、npm，以及对私有仓库 `Eveosev/dataagent` 的 GitHub SSH 读取权限。在安装过 Node.js 的普通用户终端运行，无需 npm 账号。

先安装或更新 npm 包：

```sh
npm install -g 'git+ssh://git@github.com/Eveosev/dataagent.git#feat/fde-skill-npm'
```

再按宿主运行对应命令，同一台机器只需安装一次 npm 包。若只想在一个项目试用，在项目根目录运行对应命令并加上 `--project`。

| 宿主 | 注册命令 | 在对话中指定这个 Skill |
|---|---|---|
| Codex | `dataagent-skill codex` | `$fde-engineer` |
| Claude Code | `dataagent-skill claude` | `/fde-engineer` |
| ZCode 桌面版 | `dataagent-skill zcode` | 在新任务输入框键入 `/fde-engineer`，从 **SKILLS** 中选中 `$fde-engineer`（可按 Tab）。看到技能标签后，接着输入现场委托 |
| ZCode 终端交互版 | `dataagent-skill zcode` | `/skill fde-engineer 帮我把这两份导出接成可重跑的日报` |
| DeepSeek Harness（dsh） | `dataagent-skill dsh` | `/fde-engineer 帮我查昨夜批处理的失败范围` |

重跑 npm 安装命令可跟进开发分支。固定版本时把 `#feat/fde-skill-npm` 换成目标提交的完整 SHA。遇到 ZIP 安装留下的同名目录时，命令会提示其位置。要改用 npm 管理，先把旧目录移到技能目录之外，再运行对应宿主的注册命令。[npm 的 Git 安装说明](https://docs.npmjs.com/cli/v11/commands/npm-install/)

## ZCode 和 dsh 如何接手同一件事

两者默认都扫描 `~/.agents/skills`，项目亦可共享 `.agents/skills/fde-engineer`。安装器把这个入口连到 npm 包里的完整技能目录。dsh 若设置了 `DSH_AGENTS_HOME`，个人安装遵循该目录；使用 `--project` 时按 dsh 的发现规则定位最近的 Git 根目录，没有 Git 标记时使用当前目录。

| 环节 | ZCode | dsh |
|---|---|---|
| 发现与加载 | 桌面版在输入框的 **SKILLS** 分组显示已发现的技能。搜索时，**COMMANDS** 分组可能显示 “No matching slash commands”，继续看下方的 **SKILLS**。终端可用 `zcode skills inspect fde-engineer --json` 核对路径和正文 | profile 中的 `dsh-skill-filesystem` 扫描，`dsh-skill` 注册，`dsh-tool-skill` 将名称和描述提供给模型。模型可调用 `skill` 读取正文。用户显式输入 `/fde-engineer` 时，宿主在本轮加入正文和资源目录 |
| 业务确认与续办 | 交互会话里直接答复。分进程调用时用 `zcode --resume <sessionId> -p '按门店和营业日汇总'` | 交互会话里直接答复。一次性命令用 `dsh --profile headless --session-id <sessionId> '按门店和营业日汇总'` 从同一工作目录续办 |
| 执行与交付 | 按现场可用工具取样、实现、试跑和核对结果 | 同一份 Skill 通过宿主工具工作。Python 3 可用时，可在技能目录运行随包的小样对账或引文核验工具 |

dsh 随附的 `headless` profile 包含上述三个组件。自定义 profile 若省略了技能支持，应在已有 agent 和工具服务的作用域内挂载 `@deepseek-ai/dsh-skill`、`@deepseek-ai/dsh-skill-filesystem`、`@deepseek-ai/dsh-tool-skill`。如果 profile 配置了专用扫描目录或禁用了默认目录，应让它扫描上述入口。

## 从 ZIP 安装

拿到 `fde-engineer.zip` 后，在压缩包所在目录打开终端。下面是 macOS 和 Linux 上的首次安装命令。默认装给 Codex；使用 Claude Code 时，将第一行改成 `skill_dir="$HOME/.claude/skills"`。[Codex 的个人技能目录](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills) · [Claude Code 的个人技能目录](https://code.claude.com/docs/en/skills#where-skills-live)

```sh
skill_dir="$HOME/.agents/skills"
mkdir -p "$skill_dir" && unzip -n fde-engineer.zip -d "$skill_dir"
```

解压后，入口是 `$skill_dir/fde-engineer/SKILL.md`。保留同目录下的 `references/` 和 `scripts/`。小样对账和引文核验都使用 Python 3 标准库。

## 验证

新建对话，提供两份有关联的业务样本和一份独立的期望结果，要求“按这个口径做一个本地能重跑的加工任务”。核对 Agent 是否从输入实际生成结果、交代验证差异和运行入口。排查运行故障时可改给日志与目标快照，核对它是否能区分已确认影响和仍待回读的状态。只需从文件提取制度时，直接指定原件即可。[现场工作指引](skills/fde-engineer/references/field-delivery.md)
