# DataAgent 模块与原子能力简稿

按**数据层、执行应用层、评测和治理层**讨论。一级是能力大类，二级是可独立使用和发布的原子能力；现阶段只说明作用和边界，不定义接口。

原子能力围绕一个明确目的设计，同一能力可以有多种后端或算法实现。用户、Agent 或平台可以组合出 Preset / Bundle，例如“不规则表格处理”“企业问数”。循环、重试、任务路由等由组合流程安排。

本版重新整理 DA 编号，用于讨论分类，不沿用上一版编号含义。

| 层次 | 一级模块 | 关注点 |
| --- | --- | --- |
| 数据层 | DA01 数据接入；DA02 数据准备与探查；DA03 业务语义与关系；DA04 任务轨迹与记忆 | 数据如何进入、被理解、存储和积累 |
| 执行应用层 | DA05 召回检索；DA06 NL2SQL；DA07 计算执行；DA08 分析；DA09 预测、仿真与优化；DA10 表格与可视化 | 根据任务检索、计算并交付 |
| 评测和治理层 | DA11 评测与验证；DA12 治理与资产维护 | 是否正确、可用、可共享，如何更新 |

## 一、数据层

### DA01｜数据接入

连接企业来源或导入现场文件，保留原始结构。

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA01.1 来源连接 | 接入数据库、API、MCP，管理连接与身份引用。 | 连接成功不代表来源支持执行 SQL。 |
| DA01.2 结构读取 | 获取表列、类型、键、API 字段及源端能力。 | 不推断业务含义。 |
| DA01.3 数据读取 | 按字段、条件、分页或采样读取数据。 | SQL 执行统一使用 DA07.1。 |
| DA01.4 文件解析 | 读取 Excel、CSV、JSON 和 PDF 文本层，保留 sheet、公式、坐标等结构。 | OCR 单独处理，表格规整归 DA02。 |
| DA01.5 OCR | 识别扫描 PDF 和图片中的文字、位置。 | 保留识别不确定性，不纠正业务数字。 |

### DA02｜数据准备与探查

把现场数据整理成可分析的表，并探查其结构与分布。

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA02.1 表格区域识别 | 从页面或 sheet 中定位一个或多个表块。 | 不判断业务对象是什么。 |
| DA02.2 表格结构恢复 | 识别多行表头、合并单元格、分节、重复表头、合计行及续表结构。 | 保留原值；不能确认的拼接保留待确认状态。 |
| DA02.3 数据结构转换 | 按指定规则转置、宽长转换、展开嵌套或拼接表格。 | 不替用户决定跨表业务关系。 |
| DA02.4 数据画像 | 统计结构、空值、基数、分布，推断字段类型、时间和记录粒度。 | 推断是候选，不直接成为业务定义。 |
| DA02.5 Join 关系发现 | 根据键、覆盖率、基数和历史查询寻找关联候选。 | 业务关系确认归 DA03。 |
| DA02.6 数据清洗 | 按选定规则执行去重、类型转换、标准化和缺失处理。 | 保留原件和变换记录，不静默补造事实。 |

### DA03｜业务语义与关系

维护业务对象、指标、规则及其与物理数据的对应关系。

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA03.1 实体建模 | 定义客户、订单等实体及其属性、状态和粒度。 | 不等同于物理表定义。 |
| DA03.2 身份对齐 | 识别跨系统的同一对象，维护编码和别名映射。 | 不直接覆盖业务主数据。 |
| DA03.3 关系建模 | 表达实体关系、合法 Join、基数、时态和租户条件。 | 使用探查候选，但不把值重合直接认作合法关系。 |
| DA03.4 指标与规则定义 | 定义指标公式、维度、业务规则及适用范围。 | 不执行查询；未经确认的定义保留草案。 |
| DA03.5 时间与单位定义 | 定义业务时间、财务日历、币种、单位及换算规则。 | 实际计算由执行能力完成。 |
| DA03.6 语义映射与存储 | 保存语义定义及实体、指标、规则到表列、API、文档的映射和依赖。 | 关系可用表、图等实现，不预设必须使用图数据库。 |

### DA04｜任务轨迹与记忆

区分原始执行记录、可复用经验和分析产物，使任务积累可以被后续任务使用。

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA04.1 任务轨迹存储 | 保存任务中的问题、计划、工具调用、SQL、结果引用和用户纠正。 | 可复用 AgentOS 轨迹存储；完整轨迹不等于可信经验。 |
| DA04.2 任务经验提炼 | 从轨迹提炼有效查询、分析方法、失败经验及其适用条件。 | 生成候选经验，不自动升级为企业业务规则。 |
| DA04.3 记忆存储 | 按用户、任务或企业范围保存已选择的经验和历史结论。 | 管理存储与作用域；如何找回交给 DA05。 |
| DA04.4 分析资产存储 | 保存 SQL、代码、模型、报表及可复用模板，关联数据和语义版本。 | 使用 MintHub 或现有资产存储，不重复建设通用注册服务。 |

业务关系、物理映射和指标依赖在 DA03 表达；“哪次任务用了哪个指标、生成了哪份报表”等使用关系随 DA04 记录并引用同一语义对象。原始轨迹与提炼记忆可以共享存储，逻辑上区分用途。

多 Agent 协作时，共享任务指定的数据与语义版本、已选经验及相关引用；按子任务检索和传递必要上下文，避免把全部轨迹复制给每个 Agent。

## 二、执行应用层

### DA05｜召回检索

专注把相关对象找回来，按检索对象划分。索引属于检索能力的实现，存储和资产发布分别使用数据层、治理层能力。

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA05.1 表格/数据库检索 | 检索数据集、表、列和取值，支持值反查列或表。 | 可从任意线索开始；不要求固定“表→列→值”链路。 |
| DA05.2 业务语义检索 | 查找实体、指标、规则、业务关系和对应数据映射。 | 不创建或修改业务定义。 |
| DA05.3 记忆检索 | 找回历史任务、经验、用户纠正及已验证查询。 | 区分原始轨迹、候选经验和已确认记忆。 |
| DA05.4 文档检索 | 从制度、手册、数据说明等内容中查找相关段落。 | 不把相似段落直接当作业务结论。 |
| DA05.5 分析资产检索 | 查找代码、模型、函数、报表和方法模板。 | 不执行或修改资产。 |
| DA05.6 检索重排 | 对多个检索来源的候选去重、排序和筛选。 | 不承担证据存储或最终答案验证。 |

Agent / Preset 根据当前缺口选择检索、补查或澄清；不再把“证据包组装”“轨迹存储”“发布”放进检索模块。

### DA06｜NL2SQL

把用户问题转成符合数据结构和业务口径的查询。

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA06.1 查询需求解析 | 识别指标、维度、过滤、时间及歧义，形成查询意图。 | 所需对象由 DA05 召回。 |
| DA06.2 语义查询编译 | 将已定义指标、维度和关系编译为查询。 | 不临时创造业务定义。 |
| DA06.3 SQL 生成 | 基于问题、结构和语义生成目标数据库方言的 SQL。 | 不执行 SQL；已有语义编译能力可直接复用。 |
| DA06.4 SQL 修正 | 根据错误和反馈修改 SQL。 | 不自动改口径或源数据；是否继续尝试由流程决定。 |

### DA07｜计算执行

执行已选择的查询、代码或函数。同一能力按场景适配企业端与本地环境。

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA07.1 `sql_execute` | 将 SQL 提交给指定执行后端，取回结果及执行状态。 | 不生成 SQL；后端必须实际支持 SQL。 |
| DA07.2 `code_execute` | 在指定环境执行 Python 等分析代码。 | 依赖现有运行环境和沙盒，不负责选择分析方法。 |
| DA07.3 `function_call` | 调用已登记的分析、预测或企业领域函数。 | 限于函数声明的能力和授权范围。 |

`sql_execute` 是一个可发布能力，内部可按执行场景选择适配器：

| 场景 | 执行方式 |
| --- | --- |
| 企业提供 SQL MCP/API | 通过支持 SQL 的工具或接口提交查询，轮询或直接取回结果。 |
| 企业允许直连数据库 | 通过数据库驱动执行，使用对应身份与方言。 |
| 端侧文件分析 | 将准备好的文件表挂载到本地 DuckDB，再执行查询。 |

执行目标由连接能力和任务配置决定；方言处理归生成/编译环节，执行层处理提交、异步状态、结果读取、分页、超时及取消。只有业务 API、没有 SQL 接口的来源，通过 DA01.3 或 DA07.3 使用，不能假装支持 SQL。

### DA08｜分析

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA08.1 分析规划 | 将开放问题拆成假设、方法和验证步骤。 | 不把计划当结论。 |
| DA08.2 描述分析 | 执行同比环比、贡献、漏斗、留存等分析。 | 各方法可独立发布，不直接推断因果。 |
| DA08.3 统计分析 | 提供统计估计、检验、回归等方法。 | 说明适用条件和不确定性。 |
| DA08.4 关系分析 | 分析对象间路径、聚集和异常关系。 | 使用已有对象关系，不做实体对齐。 |
| DA08.5 结果解释 | 根据计算结果解释变化、提出原因假设并回答问题。 | 假设与已验证结论分开，保留来源引用。 |

这些方法可在能力内部复用 DA07 执行，或调用已提供的领域函数；不为每个业务问题再造一套执行引擎。

### DA09｜预测、仿真与优化

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA09.1 预测 | 根据历史数据和指定模型估计未来，给出预测区间。 | 不承诺未来结果准确。 |
| DA09.2 情景仿真 | 计算不同参数、假设和机制下的情景。 | 仿真依赖假设，不等同于预测。 |
| DA09.3 约束求解 | 在目标和约束下计算方案。 | 不替业务决定目标或执行方案。 |
| DA09.4 方案比较 | 比较方案的成本、收益、风险等权衡。 | 使用明确的偏好与权重。 |

### DA10｜表格与可视化

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA10.1 表格计算 | 生成结果表、透视表和公式计算。 | 输入表格规整归 DA02。 |
| DA10.2 图表生成 | 将结果转换为图表或交互视图。 | 不改变分析口径。 |
| DA10.3 报告生成 | 组织文字、表格、图表和引用，导出报告或看板。 | 调度与分享由应用组合。 |

## 三、评测和治理层

### DA11｜评测与验证

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA11.1 数据质量检查 | 检查缺失、重复、类型、约束及跨源对账。 | 调用 DA02 的画像，不重复做数据准备。 |
| DA11.2 查询结果验证 | 检查 SQL、语义口径、时间、Join 膨胀和结果一致性。 | SQL 可执行不等于业务正确。 |
| DA11.3 方法效果评估 | 检查统计方法、预测回测、仿真校准和方案可行性。 | 按方法分别评估，不统一成一个正确率。 |
| DA11.4 回归评测 | 在固定案例上评估检索、问数和分析流程，比较质量、成本与延迟。 | 固定必要版本，不能复原时说明限制。 |

### DA12｜治理与资产维护

| 原子能力 | 作用 | 边界 |
| --- | --- | --- |
| DA12.1 权限与敏感信息管理 | 管理数据、记忆、检索及导出的访问与脱敏要求。 | 复用平台和源端控制，并在各使用环节生效。 |
| DA12.2 资产版本管理 | 管理数据引用、语义、记忆和分析资产的版本、失效及发布状态。 | 包版本不能替代数据版本；不承诺任意历史都可重算。 |
| DA12.3 反馈与更新建议 | 汇总用户纠正、错误和漂移，提出资产更新建议。 | 建议与共享资产更新分开，重要变更可交业务审阅。 |

运行、审批、审计和包分发按现有 AgentOS / MintHub 能力接入；本稿先聚焦 DataAgent 的能力划分，不展开平台机制。
