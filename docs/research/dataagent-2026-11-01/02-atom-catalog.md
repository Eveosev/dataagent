# DataAgent 原子能力清单（v0.2）

**读法：** 一个原子 = 一个契约、一个验收集、一个 owner。作用 = 它保证什么；边界 = 它明确不做什么。原子不带优先级，优先级属于 preset。

## DA01 数据接入与任务数据空间（10）

> 模块边界：仅作输入数据的接入；不与业务挂钩，不作是否可用的判断

- DA01.1 来源注册和接口登记 — 
  - 作用：登记源、凭据引用、限流、许可。
  - 边界：不读内容，不判可用。
- DA01.2 库/API 结构解析 — 
  - 作用：schema、嵌套、分页、类型映射。
  - 边界：不解析文件，不做画像。
- DA01.3 快照、as-of 与可重放 — 
  - 作用：固定“读的是哪一版”，支持重放。
  - 边界：不保证源端不再变，只保证可追溯。
- DA01.4 任务数据空间 — 
  - 作用：隔离临时表、中间结果、生命周期、配额。
  - 边界：不做跨任务持久化。
- DA01.5 读取契约与降级 — 
  - 作用：分页、采样、截断、重试、失败语义。
  - 边界：不修数据，不定采样策略。
- DA01.6 数据边界与授权传递 — 
  - 作用：读取/索引/缓存/导出/上下文都不放大权限。
  - 边界：不做审批，不定义脱敏规则。
- DA01.7 文件读取与格式适配 — 
  - 作用：xlsx/csv/pdf 文本层、多 sheet、编码、公式双轨。
  - 边界：不判表头，不切块。
- DA01.8 布局切块 — 
  - 作用：按空行/样式/合并区切出候选块。
  - 边界：不判哪块是真表，不跨 sheet 合并。
- DA01.9 表头与合并单元格归一 — 
  - 作用：多行表头、合并展开、单位、脚注 → 逻辑表。
  - 边界：不修脏数据，不做业务口径。
- DA01.10 文档版面与表格抽取（OCR） — 
  - 作用：扫描件/图片 → 文本与表格结构。
  - 边界：不保证识别正确（需 DA02 校验），不做版式还原。

## DA02 探查与画像（7）

> 模块边界：只判断数据能不能用；不改数据，不定业务口径

- DA02.1 结构画像 — 
  - 作用：列、类型、空列、重复列、嵌套。
  - 边界：不判质量达标。
- DA02.2 取值与分布画像 — 
  - 作用：空值、基数、频率、枚举、代表样本。
  - 边界：不做实体识别，不做语义。
- DA02.3 时间与粒度识别 — 
  - 作用：事件/业务/更新时间、时区、周期、grain。
  - 边界：不定时间口径。
- DA02.4 质量与异常初筛 — 
  - 作用：缺失、重复、类型冲突、突变、跨源不一致。
  - 边界：不修复，不做最终判定。
- DA02.5 关系与 join 候选 — 
  - 作用：PK/FK、名称/类型/覆盖、历史 SQL、基数。
  - 边界：不确认实体身份，不生成 join SQL。
- DA02.6 探查计划与覆盖报告 — 
  - 作用：预算内下一步、未覆盖区、索引缺口。
  - 边界：不做召回，不做停止决策。
- DA02.7 信任等级推断 — 
  - 作用：来源/公式/导出标记 → 三档 + 证据。
  - 边界：不替用户签字，不封锁数据。

## DA03 数据质量与修复（6）

> 模块边界：只判定质量并修复；不做画像，不验证答案

- DA03.1 结构与取值契约 — 
  - 作用：列存在、类型、唯一、非空、范围、枚举。
  - 边界：不画像，不定业务规则。
- DA03.2 跨表对账与一致性 — 
  - 作用：总分、余额、计数、FK 覆盖、时间连续。
  - 边界：不做业务口径判断。
- DA03.3 异常与缺失定位 — 
  - 作用：记录/分区/模式；业务变化 vs 数据错误。
  - 边界：不修复，不判答案。
- DA03.4 修复方案生成 — 
  - 作用：去重、标准化、补齐、值映射候选。
  - 边界：不执行，不审批。
- DA03.5 修复执行与复核 — 
  - 作用：隔离执行、前后对比、可回滚。
  - 边界：不决定该不该修，不写生产库。
- DA03.6 质量事故影响分析 — 
  - 作用：沿血缘定位受影响指标/报表。
  - 边界：不采集血缘，不做修复。

## DA04 实体、身份与 Ontology（6）

> 模块边界：只认定是不是同一个对象；不定指标，不做全量本体推理

- DA04.1 概念与实体类型提取 — 
  - 作用：从 schema/文档/指标/问题形成对象类型。
  - 边界：不定义指标，不做推理引擎。
- DA04.2 稳定身份与主数据对齐 — 
  - 作用：主键、自然键、别名、跨系统编码、合并拆分。
  - 边界：不做 MDM 全流程，不写业务系统。
- DA04.3 粒度与状态模型 — 
  - 作用：行/事件/版本/有效期/状态变化。
  - 边界：不定时间口径，不做 SCD 实现。
- DA04.4 对象关系与约束 — 
  - 作用：1:1/1:N/N:N、桥表、时态、合法路径。
  - 边界：不生成 join，不做图分析。
- DA04.5 Ontology 映射与实例化 — 
  - 作用：对象/属性/关系 → 表列/API。
  - 边界：不做推理引擎，不做语义发布。
- DA04.6 冲突与版本 — 
  - 作用：同名对象、跨域冲突、合并变更。
  - 边界：不做主数据治理流程，不审批。

## DA05 语义层、指标与规则（7）

> 模块边界：只定义并编译业务含义；不取数，不召回证据

- DA05.1 指标与度量定义 — 
  - 作用：公式、过滤、分子分母、聚合、可加性。
  - 边界：不取数，不做可视化。
- DA05.2 维度与可切分范围 — 
  - 作用：适用实体、粒度、合法组合。
  - 边界：不做权限，不做查询优化。
- DA05.3 时间、日历与单位 — 
  - 作用：事件/下单/支付/结算、时区、财历、币种。
  - 边界：不做预测。
- DA05.4 业务规则与例外 — 
  - 作用：阈值、排除、优先级、来源、生效范围。
  - 边界：不做质量规则，不审批。
- DA05.5 语义编译与解释 — 
  - 作用：指标 → 计划/SQL/函数；explain；缓存。
  - 边界：不执行 SQL，不验证结果。
- DA05.6 语义发布与历史重现 — 
  - 作用：draft→validated→published→deprecated。
  - 边界：不做审批流，不做资产目录。
- DA05.7 指标健康与语义运维 — 
  - 作用：使用度、漂移、冲突、废弃、owner。
  - 边界：不做线上监控，不做血缘。

## DA06 检索与证据（7）

> 模块边界：只找该看什么、凭什么；不定语义，不生成 SQL

- DA06.1 多入口问题理解 — 
  - 作用：值/列/指标/规则/SQL/文件/会话对象。
  - 边界：不判任务类型，不定义语义。
- DA06.2 类型化对象索引 — 
  - 作用：表/列/值/实体/指标/规则/代码/文档。
  - 边界：不做接入，不做画像。
- DA06.3 反向定位与渐进导航 — 
  - 作用：值→列/实体；列→指标；ID→详情。
  - 边界：不生成查询，不做分析。
- DA06.4 缺口驱动的下一动作 — 
  - 作用：按冲突/缺字段/未知值选下一步。
  - 边界：不执行，不停止。
- DA06.5 证据与权限感知召回 — 
  - 作用：来源、版本、匹配方式、ACL、新鲜度。
  - 边界：不做权限判定，不做脱敏。
- DA06.6 停止、澄清与回退 — 
  - 作用：充分性检查、预算、受限结果显式返回；也是通用澄清策略。
  - 边界：不做业务裁决，不审批。
- DA06.7 认证查询库（VQ）与复用 — 
  - 作用：问题→认证 SQL/计划；命中、改写、失效。
  - 边界：不做 SQL 生成，不做语义发布。

## DA07 问数与查询生成（6）

> 模块边界：只把问题变成可执行查询；不做深度归因，不放行结果

- DA07.1 任务类型识别与澄清 — 
  - 作用：问数/解释/对比/下钻/追问/不可回答。
  - 边界：不定语义，不做深度分析。
- DA07.2 候选绑定与查询计划 — 
  - 作用：实体/指标/维度/值/时间/产物角色。
  - 边界：不召回，不执行。
- DA07.3 语义查询优先与 fallback — 
  - 作用：受控计划优先，未建模走有界 NL2SQL。
  - 边界：不编译语义，不验证。
- DA07.4 SQL 生成与安全检查 — 
  - 作用：参数化、AST、只读、范围、预算、超时。
  - 边界：不做权限策略，不做优化器。
- DA07.5 执行反馈与有界修复 — 
  - 作用：空集/错误/膨胀；小查询验证；循环上限。
  - 边界：不做根因，不修数据。
- DA07.6 答案解释与引用 — 
  - 作用：定义、时间、版本、SQL、假设、限制。
  - 边界：不做证据包，不排版。

## DA08 深度分析与诊断（6）

> 模块边界：只解释为什么；不取数，不预测

- DA08.1 问题到分析计划 — 
  - 作用：目标、假设、数据、方法、检验、交付条件。
  - 边界：不取数，不预测。
- DA08.2 描述性 BI 分析 — 
  - 作用：同比环比、分组、贡献、漏斗、留存、分层。
  - 边界：不做因果，不做可视化实现。
- DA08.3 统计分析与不确定性 — 
  - 作用：分布、相关、回归、检验、区间。
  - 边界：不做因果识别，不做预测部署。
- DA08.4 异常与根因调查 — 
  - 作用：时间、结构、维度、关系；贡献 vs 因果。
  - 边界：不修复，不建议决策。
- DA08.5 关系与网络分析 — 
  - 作用：多跳、聚集、路径、异常结构。
  - 边界：不做实体对齐，不做图数据库。
- DA08.6 可复现分析工程 — 
  - 作用：代码、查询、参数、中间结果、版本。
  - 边界：不排版，不做评测。

## DA09 表格、BI 与可视化交付（6）

> 模块边界：只把结果变成可交付产物；不验证，不接入

- DA09.1 表格清洗与结构整理 — 
  - 作用：多 sheet、表头、类型、合并；保留原件。
  - 边界：不解析入库，不修数据。
- DA09.2 透视、公式与计算 — 
  - 作用：透视、分组、查找、公式；重算与缓存。
  - 边界：不定指标，不执行 SQL。
- DA09.3 图表与交互探索 — 
  - 作用：图表选择、筛选、下钻；绑定参数保留。
  - 边界：不做统计分析，不做叙事。
- DA09.4 报告与 dashboard — 
  - 作用：指标+图表+解释+证据；可更新。
  - 边界：不生成证据，不做订阅调度。
- DA09.5 可编辑可复跑产物 — 
  - 作用：SQL/Python/Notebook/表格/报告源文件。
  - 边界：不做执行环境，不做版本管理。
- DA09.6 导出、分享与刷新 — 
  - 作用：PDF/XLSX/CSV/图片/嵌入；权限与截至时间。
  - 边界：不做外发审批，不做脱敏。

## DA10 预测、仿真与优化（6）

> 模块边界：只做外推与决策；不解释历史，不取数

- DA10.1 时间序列与概率预测 — 
  - 作用：目标、粒度、窗口、外生变量、区间。
  - 边界：不做历史解释，不做数据准备。
- DA10.2 回测、基线与漂移 — 
  - 作用：时间切分、rolling、naive 对比、误差。
  - 边界：不做模型上线，不做题集。
- DA10.3 情景与 what-if — 
  - 作用：假设、参数、机制、敏感性。
  - 边界：不做约束求解，不审批。
- DA10.4 约束建模与求解 — 
  - 作用：硬软约束、资源、顺序、容量、不可行原因。
  - 边界：不做多目标权衡，不执行。
- DA10.5 多目标方案比较 — 
  - 作用：成本、质量、交付、风险；权重与版本。
  - 边界：不做决策签字，不做预测。
- DA10.6 建议、执行反馈与校准 — 
  - 作用：方案边界、实际跟踪、模型修订。
  - 边界：不做业务执行，不审批。

## DA11 验证、治理与业务交付（6）

> 模块边界：只判定能不能信、能不能发；不生成答案，不做题集

- DA11.1 数据与查询验证 — 
  - 作用：绑定、过滤、时间、单位、空集、膨胀、守恒。
  - 边界：不定语义，不修数据。
- DA11.2 语义与口径验证 — 
  - 作用：定义、版本、规则、例外、生效时间、as-of。
  - 边界：不发布，不审批。
- DA11.3 统计与方法验证 — 
  - 作用：样本、基线、回测、区间、泄漏、假设。
  - 边界：不做统计计算，不做预测。
- DA11.4 权限、脱敏与外发治理 — 
  - 作用：身份、行列、采样、缓存、索引、导出、跨境。
  - 边界：不做身份认证（AgentOS），不审批。
- DA11.5 人审、审批与责任 — 
  - 作用：风险分级、审阅人、异议、授权。
  - 边界：不做验证判定，不做工单系统。
- DA11.6 证据化结果包 — 
  - 作用：问题、输入、计划、版本、调用、结果、来源、限制。
  - 边界：不排版，不存轨迹。

## DA12 反馈、评测与资产演进（6）

> 模块边界：只把一次任务变成下一次能力；不做线上验证，不做血缘

- DA12.1 运行轨迹记录 — 
  - 作用：问题、候选、检索、工具、SQL、结果、成本。
  - 边界：不归因，不监控。
- DA12.2 错误归因与反馈结构化 — 
  - 作用：源/探查/语义/召回/计划/SQL/交付。
  - 边界：不修复，不提提案。
- DA12.3 修订提案与资产提升 — 
  - 作用：映射、指标、规则、示例、函数。
  - 边界：不审批，不发布。
- DA12.4 离线回放与回归题集 — 
  - 作用：固定数据、语义、权限、工具版本重放。
  - 边界：不做线上验证，不做标注平台。
- DA12.5 线上漂移与失效监测 — 
  - 作用：schema、值、分布、关系、规则、模型。
  - 边界：不做血缘，不修复。
- DA12.6 版本发布、回滚与复用 — 
  - 作用：语义、索引、函数、题集；兼容矩阵。
  - 边界：不审批，不做资产目录。

## DA13 运行态、成本与可观测（6）

> 模块边界：只保证稳定、可负担、可诊断；不管业务语义，不管建库

- DA13.1 任务生命周期与 SLO — 
  - 作用：排队、超时、取消、重试、幂等、恢复。
  - 边界：不做业务重试，不做调度。
- DA13.2 成本预算与归因 — 
  - 作用：token、扫描量、算力；租户、任务、配额。
  - 边界：不做计费系统，不做优化。
- DA13.3 延迟与体验 — 
  - 作用：首字、流式、预热、缓存、并发。
  - 边界：不做语义缓存，不做前端。
- DA13.4 遥测与追踪 — 
  - 作用：trace/span、事件字段；与轨迹对齐。
  - 边界：不做归因，不做审计。
- DA13.5 容量与隔离 — 
  - 作用：租户、队列、资源池、限流。
  - 边界：不做权限，不做沙盒（AgentOS）。
- DA13.6 健康与降级 — 
  - 作用：依赖健康、熔断、降级路径、人工接管。
  - 边界：不做故障修复（运维），不做业务降级。

## DA14 资产图与血缘（6）

> 模块边界：只管资产身份与影响面；不定语义，不做监控

- DA14.1 资产身份与命名 — 
  - 作用：稳定 ID/URN、类型、owner、租户、保留期。
  - 边界：不定语义，不做权限。
- DA14.2 血缘采集 — 
  - 作用：查询级→表列；语义→物理；任务→产物。
  - 边界：不做影响判定，不做质量。
- DA14.3 影响面分析 — 
  - 作用：变更、故障、撤权沿血缘定位。
  - 边界：不修复，不审批。
- DA14.4 资产目录与检索 — 
  - 作用：可发现、认证状态、质量分、使用度。
  - 边界：不做数据检索，不做推荐。
- DA14.5 资产生命周期 — 
  - 作用：认证、废弃、归档、迁移、兼容矩阵。
  - 边界：不发布，不审批。
- DA14.6 跨环境一致性 — 
  - 作用：dev/prod、多租户、版本 pin。
  - 边界：不做部署（AgentOS），不做数据同步。

## DA15 建模、转换与调度（6）

> 模块边界：只把源数据变成可查询数据集；不接入，不定语义

- DA15.1 转换 DAG 与依赖 — 
  - 作用：SQL/Python 转换、依赖图、增量全量。
  - 边界：不调度执行，不定语义。
- DA15.2 物化与增量 — 
  - 作用：物化视图/表、增量合并、快照。
