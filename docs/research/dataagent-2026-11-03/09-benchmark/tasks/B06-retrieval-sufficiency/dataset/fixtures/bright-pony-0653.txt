## Essential Problem:

The problem is to write a function `defangIPaddr` that takes a valid IPv4 address as input and returns a defanged version of that address. Defanging involves replacing every period "." with "[.]".

## Relevant Information:

* **IPv4 address format:**
    * Consists of four decimal numbers separated by periods.
    * Each decimal number is between 0 and 255.
    * Example: "127.0.0.1"
* **Defanging:**
    * Replace each period "." with "[.]".
    * Example: "127[.]0[.]0[.]1"

## Algorithm:

1. **Split the input string:**
    * Use the `split()` function to split the input string based on the delimiter ".".
    * This will create a list of four decimal numbers.
2. **Iterate through the list:**
    * For each element in the list:
        * Replace "." with "[.]" using the `replace()` function.
    * Append the modified element to a new list.
3. **Join the list:**
    * Use the `join()` function to join the elements in the new list back into a string using "." as the delimiter.
4. **Return the defanged IP address:**
    * Return the defanged IP address string.

## Draft Answer:

```pony
fun defangIPaddr(address: String): String =>
    address.split('.')
           .map(|chunk| chunk.replace('.', '[.]'))
           .join('.')
```

## Additional Thoughts:

* This solution assumes the input is a valid IPv4 address. Error handling could be added to handle invalid input.
* The solution uses list comprehensions for iterating and modifying elements. This is a concise and efficient way to achieve the desired result.
* The `replace()` function is used to replace the "." with "[.]". This ensures the output matches the expected format.
* The `join()` function is used to combine the modified elements back into a string with the "." delimiter.
