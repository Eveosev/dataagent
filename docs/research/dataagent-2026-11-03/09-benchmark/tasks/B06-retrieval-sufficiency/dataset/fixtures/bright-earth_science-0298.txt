## Understanding CMIP6 VARIANT-IDs

The CMIP6 dataset uses a specific identifier called a VARIANT-ID to distinguish between different simulations within an experiment. This identifier follows the format `r<k>i<l>p<m>f<n>`, where each character represents a specific aspect of the simulation configuration:

* **r**: Realization number (k): This indicates the repetition of the same experiment with different initial conditions. Values of k typically range from 1 to 100.
* **i**: Initialization method (l): This specifies the method used to initialize the model. Different methods can lead to variations in the initial state of the climate system.
* **p**: Physics configuration (m): This refers to the specific configuration of the physical parameterizations used in the model. Different physics configurations can affect the model's response to external forcing.
* **f**: Forcing configuration (n): This indicates the specific forcing scenario used in the simulation. Different forcing scenarios represent different pathways of future climate change.
