## Essential Problem:

The essential problem is to replace each element in an array with the largest element to its right. The last element should be replaced with -1.

## Relevant Information:

* **Array Iteration:** We need to iterate through the array from right to left, as we need to compare each element with the elements to its right.
* **Maximum Value Tracking:** We need to keep track of the maximum value encountered so far while iterating from right to left.
* **Array Modification:** We need to modify the original array by replacing each element with the maximum value encountered so far.

## Draft Answer:

Here's a possible solution in Pony:

```pony
fun replaceElements(arr: Array[I32]): Array[I32] =>
  var max = arr[-1]
  var result = Array[I32](arr.len)
  for i in (arr.len - 2)..0 by -1
    result[i] = max
    if max < arr[i]
      max = arr[i]
  result[-1] = -1
  return result
```

**Explanation:**

1. We initialize `max` with the last element of the array.
2. We create a new array `result` with the same length as the input array.
3. We iterate through the input array from the second last element to the first element (using a reverse loop).
4. For each element, we compare it with the current `max` value. If the element is greater than `max`, we update `max` with the element's value.
5. We assign the current `max` value to the corresponding position in the `result` array.
6. Finally, we replace the last element of `result` with -1.
7. We return the modified `result` array.

This solution iterates through the array once and keeps track of the maximum value encountered so far. It modifies the original array in-place, making it efficient in terms of time and space complexity.
