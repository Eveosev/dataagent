# 四、依赖关系

模块之间按任务建立依赖，不规定固定主链。任务可从表、列、值、文档、经验或已有 Skill 进入；Agent 按发现反复检索、补充语义、修正计划、生成程序和验证。已有可用资产时无需重走全部接入与建模步骤。

```text
任务 / 表列值 / 文档 / 经验
  ↔ DA05 检索数据、语义、经验与组件
  ↔ DA06 计划与重组 ↔ DA08.6 程序生成与修复
  ↔ DA07 执行 ↔ DA11 验证 → DA08/09/10 业务结果
  验证不足 → 补数 / 语义修订 / 方法替换 / 组件重选 / 再执行

DA01/02 按需提供数据与探查；DA03 维护业务语义
已认证指标经 DA06.8 委托外部语义层编译；新问题走 DA06.2/06.3，由 DA05.9 判断检索是否充分
DA04 保存轨迹与有效资产；DA12 管理授权约束、版本与审计
DA15 声明动作要求，DA16 按策略授权与审批，DA07 实施执行控制
DA17 提供业务环境配置与协作上下文
DA18 将有效方法和组件组合沉淀为 Skill / Preset / Bundle
业务验收比较端到端效果；方法与中间流程允许不同
```
