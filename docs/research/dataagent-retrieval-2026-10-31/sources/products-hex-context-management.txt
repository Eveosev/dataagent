Context Management
Manage guides, endorsements, and semantic models that power agents across your workspace.
📄️Guides
Provide unstructured context that helps agents interpret questions and respond appropriately.
📄️Endorsements
Mark trusted data assets in Context Studio so agents and users prioritize reviewed schemas, tables, projects, and semantic models.
📄️Models
Connect and manage Semantic Models in the Context Studio.
📄️Reference repositories
Connect to git repositories to provide the Hex Agent with richer context
📄️Context Sync
Programmatically sync guides and semantic projects into Hex from an external source of truth, such as a git repository.
📄️External Apps
Connect Hex's agent via MCP to external apps like Notion, Linear, or your own custom MCP-compatible tools.
