read_xlsx / COPY … (FORMAT xlsx) ignore the 1904 date system (dates 1462 days early)#104
Copy link
Description
seanspicer
opened on Oct 6, 2026
Issue body actions
What happens
For a workbook saved with the 1904 date system (<workbookPr date1904="1"/> in xl/workbook.xml, e.g. older Mac Excel files or "Use 1904 date system" checked), date cells are converted with the 1900 epoch. A cell showing 2024-01-01 in Excel reads as 2019-12-31, 1462 days early. Same result from read_xlsx and COPY … FROM 'f.xlsx' (FORMAT xlsx).
Repro (DuckDB 1.5.4, excel extension f4c72b5)
In Excel, File → Options → Advanced → "Use 1904 date system", type 2024-01-01 in A2 (header d in A1), save as t1904.xlsx.
SELECT * FROM read_xlsx('t1904.xlsx'); returns 2019-12-31, expected 2024-01-01.
Expected
Honour date1904 from workbookPr when converting serial dates (offset 1462 days).
Note
Found in native DuckDB and in DuckDB-WASM (same extension commit).
