@elisabethloiperdinger There is no Docker Hub repository available for pandasai, so the image is built directly from the provided Dockerfile. It’s possible that the issue is related to the connection with the Docker or podman.
Also, you can pass the Dockerfile path to the sandbox from outside, but you should check the example Dockerfile here for reference:
https://github.com/sinaptik-ai/pandas-ai/blob/main/extensions/sandbox/docker/pandasai_docker/Dockerfile

Hi, @elisabethloiperdinger. I'm Dosu (https://dosu.dev), and I'm helping the pandas-ai team manage their backlog and am marking this issue as stale.
Issue Summary:
You encountered a 403 Client Error using the pandasai-docker sandbox with Podman on RHEL 9.6.
The error was due to the pandasai-sandbox image not being found on Docker Hub.
A maintainer clarified there is no prebuilt image on Docker Hub; the image must be built locally from the provided Dockerfile.
The 403 error likely resulted from attempting to pull a non-existent image.
The recommended solution was to build the image locally and pass the Dockerfile path to the sandbox as shown in the repository example.
Next Steps:
Please confirm if this issue is still relevant with the latest version of pandas-ai.
